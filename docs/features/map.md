# 校园地图

## 地图浏览

打开「校园导览」，展示校园地图，包含以下地点标注：

| 类别    | 包含地点                           |
| ------- | ---------------------------------- |
| 🏫 教学 | 各学院楼、公共教学楼、图书馆       |
| 🏠 宿舍 | 各宿舍楼、研究生公寓               |
| 🍔 餐饮 | 各食堂、小吃街、咖啡厅             |
| 🏥 服务 | 校医院、校园卡中心、打印店、快递点 |
| ⚽ 运动 | 操场、体育馆、篮球场、游泳馆       |

## 地点搜索

点击顶部搜索框进入搜索页，支持按**名称、别名或简介**模糊搜索：

- **最近搜索**：自动记录历史，可一键清空、点击复用
- **热门地点**：按浏览量排序，未输入关键词时展示
- **搜索结果**：实时显示命中数量，点击进入地点详情

## 地点详情

点击地图标记点或搜索结果，进入详情页查看：

- 地点图片画廊（点击可预览大图）
- 名称、别名与分类标签
- 详细简介
- 内嵌迷你地图与定位标记
