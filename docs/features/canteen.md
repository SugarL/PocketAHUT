# 食堂菜品

干饭人必备功能——看看各个食堂窗口卖什么、多少钱、评价怎么样。

我们收集了本部和东区的所有窗口，进行了数据录入，目前食堂功能分为三个，分窗口查询，菜品名查询(自带比价)以及评论

## 菜品查询

进入「菜品查询」页面，可以按条件筛选：

| 筛选条件 | 说明               |
| -------- | ------------------ |
| 校区     | 本部 or 东区       |
| 食堂     | 具体哪个食堂       |
| 窗口     | 具体哪个窗口       |
| 分类     | 面食、荤菜、素菜等 |
| 价格区间 | 设置最低和最高价   |

每条菜品显示名称、窗口、价格，帮你快速锁定想吃的。

## 菜品比价

我们的设计理念是用比价来代替查询，单一的查询并没有实际的用处，不如把某一类的全部进行比价，来供同学们挑选

同一个菜，不同食堂不同价？比价功能帮你找最实惠的：

1. 选择菜品分类（如「拌面」）
2. 输入菜品关键词（如「鸡腿」）
3. 系统会列出**全校各食堂**这个菜的价格对比

比价结果还会统计**最高价、最低价**

## 窗口评论

觉得哪个窗口好吃或者踩雷了？给它评论：

1. 在「菜品查询」中选择具体窗口
2. 进入窗口评论页，输入评价并提交
3. 评论支持分页加载（向下滚动加载更多），可删除自己发表的评论
4. 评论经管理员审核后显示

食堂页内的「社区」板块可浏览热门与随机评论，下拉或点击按钮刷新。

::: tip 注意
评论仅用于参考，不代表真实评价，管理员会审核，审核后才会显示
:::

## 数据来源

菜品数据由管理员维护，定期更新。如果你发现有窗口关门了或者涨价了，欢迎反馈。
