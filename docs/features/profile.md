# 个人中心

「我的」是底部三个主 Tab 之一，集中管理账号、资料与项目相关入口。

## 我的页

- **头像与昵称**：默认使用 QQ 头像（绑定 QQ 后）或自定义头像，昵称为用户名；未登录显示「未登录」
- **账号管理**
  - 高级功能：进入 [定时提醒等高级能力](/features/personalize)
  - 绑定账号：绑定教务系统 / 宿舍系统 / 智慧校园（详见 [系统账号说明](/guide/account)）
  - 宿舍绑定：绑定宿舍后可使用电费、洗衣机等功能
- **其他**：设置、支持我们（观看激励视频）、意见反馈、免责声明、关于我们
- 已登录时显示「退出登录」；底部展示应用名称与版本号

## 关于我们

展示 Logo、当前版本号、主创团队寄语、核心功能一览，并注明项目为 **MIT 开源**。Android 端可在此「检查更新」。

## 个人设置

进入「我的 → 个人设置」（未登录时点头像引导登录）：

- **基础资料**：头像、用户名、QQ 号
- **邮箱**：绑定或更换邮箱，需先获取验证码（倒计时防重复发送）
- **密码**：设置或修改密码，至少 6 位；各输入框可独立切换明文/密文

## 绑定账号

在「我的 → 绑定账号」中绑定校园各系统账号，支持为账号开启 **VPN**。具体各系统的账号、初始密码与用途见 [系统账号说明](/guide/account)。已绑定列表可解绑或切换 VPN 状态。

## 意见反馈与支持

- **意见反馈**：引导加入用户群，帮助改进产品
- **支持我们**：观看激励视频广告，为项目做贡献（见 [会员功能](/features/personalize)）
