# 个性化设置

口袋安小工提供了细粒度的外观与功能定制，让每个人都能调出顺手的样子。入口分两处：

- **我的 → 设置**：首页功能区、字体设置、主题色系、安卓端设置
- **我的 → 高级功能**：会员功能、定时提醒等高级能力

## 首页功能区

决定首页网格里显示哪些功能、以什么顺序出现，以及顶部两个快捷入口。

1. 进入「设置 → 首页功能区」
2. **快捷入口**：从全部功能中选 2 个放到首页顶部大卡片
3. **功能区排序**：用箭头调整顺序，用眼睛图标切换显隐
4. 点击「保存设置」生效（配置保存在本地）

## 字体设置

- **字体大小**：滑块调节全局字号（`--font-scale`），立即生效
- **系统字体**：默认 / 黑体 / 楷体
- **网络字体**：从网络加载更多字体，首次加载需等待并自动缓存到本地；加载中显示进度，失败会提示检查网络

## 主题色系

切换界面主色系、自定义主色与背景，整体外观跟随变化。点按对应区域弹出取色面板确认即可。

## 安卓端设置

> 仅 H5 网页端可见（由 `#ifdef H5` 控制，Android App 与小程序不显示该入口）。

- **小组件透明度**：调节桌面小组件背景与内容透明度（0% 不透明 ~ 100% 全透明），透明后透出桌面壁纸
- **底部安全区**：手势导航下底部小白条可能遮挡导航栏，拖动滑块增加底部偏移量，附实时预览

## 会员功能

项目为开源维护，开发不易。在「我的 → 高级功能」中选择「我已捐助」或「我已宣传」，即可解锁全部高级功能（本地标记，无需付费验证）。

## 高级功能（需会员）

解锁后可配置服务端定时任务：

| 功能             | 说明                                                   |
| ---------------- | ------------------------------------------------------ |
| 电费低余额提醒   | 按时间窗口与检查间隔扫描宿舍电量，低于阈值时邮件通知   |
| 成绩更新提醒     | 按时间窗口与检查间隔检测新成绩，第一时间邮件推送       |

- 电费提醒可分别设置**空调告警阈值**与**房间告警阈值**
- 检查间隔可选 30 分钟 ~ 24 小时
- 提醒由服务端定时执行，命中条件时发送邮件到你绑定的邮箱

同一页还可开关**激励视频广告**与**原生广告**，用于支持项目。
