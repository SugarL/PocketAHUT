# 功能服务

「服务」是底部三个主 Tab 之一，把全部功能按分类聚合，方便从一处直达。适合不想翻首页网格、想按类别浏览的场景。

## 页面结构

- **左侧分类栏**：教务学习 / 校园生活 / 资讯。点击切换右侧内容。
- **右侧功能网格**：当前分类下的所有功能卡片，点击即可进入对应页面。

## 使用说明

| 情况                 | 行为                                       |
| -------------------- | ------------------------------------------ |
| 点击功能卡片         | 跳转到对应功能页                           |
| 功能需要登录未登录   | 提示「请先登录」并引导到登录页             |
| 校园集市             | 暂未开放，点击弹出「敬请期待」提示         |

「校园集市」是规划中的校内二手交易入口，目前仅占位，后续版本开放。

## 与首页的关系

服务页的功能集合与首页功能区一致，只是换了一种「分类浏览」的入口。你仍可以在 [个性化设置](/features/personalize) 中调整首页功能区的排序与显示。
