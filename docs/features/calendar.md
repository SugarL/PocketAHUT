# 校历

校历把学期里的关键节点——开学、放假、考试周、节假日等——集中在一张月历上，和你的课表叠在一起看，重要日子不再错过。

## 日历浏览

打开底部「服务」或在首页功能区进入「校历」，页面分为上下两部分：

- **日历卡片**：展示当前月，校历活动标注在对应日期格内。某天有多个活动时，只显示第一条，其余以 `+N` 呈现。
- **当日课表卡片**：显示选中日期的课程；未导入课表或当天无课时显示空状态。

操作方式：

| 操作           | 效果                       |
| -------------- | -------------------------- |
| 左右箭头 `‹ ›` | 上一个月 / 下一个月        |
| 点击月份标题   | 快速回到「今天」所在月份   |
| 点击某个日期   | 选中该天并刷新下方课表     |
| 下拉刷新       | 重新加载校历活动与当日课表 |

## 课表叠加

选中某天后，下方会按已导入的课表展示当天的课程（课程名、节次、时间）。校历活动本身来自后端配置，由管理员维护；**要看到某天的课程，需先到「课表」页面导入教务课表**。

## 数据说明

- 校历节点由管理员在后台配置，内容以实际发布为准。
- 课表数据依赖你已绑定的教务账号与导入的学期设置。
