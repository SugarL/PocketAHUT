# 消息通知

::: warning 🚧 部分功能开发中
以下通知类型为规划内容，实际推送能力以上线版本为准。**目前已支持应用内公告通知。**
:::

## 当前已支持

- **应用内公告**：重要公告与免责声明会在首页以弹窗形式展示，首次启动会提示阅读免责声明。
- 公告内容由后台配置，打开 App 时自动检查并弹出。

## 规划中的通知类型

### 教务通知

| 通知类型     | 触发时机                 |
| ------------ | ------------------------ |
| 考试成绩发布 | 教务处录入成绩后         |
| 选课提醒     | 选课开始前 1 天 + 1 小时 |
| 补考安排     | 补考时间发布后           |
| 四六级报名   | 报名开始通知             |
| 调课 / 停课  | 教务处发布后实时推送     |

### 生活通知

| 通知类型       | 触发时机             |
| -------------- | -------------------- |
| 校园卡消费异常 | 单笔消费超过设定阈值 |
| 校园卡余额不足 | 余额低于设定阈值     |
| 图书到期提醒   | 到期前 3 天 + 当天   |
| 寝室电费余额   | 电费低于设定阈值     |

## 规划中的推送渠道

| 渠道           | 说明                     |
| -------------- | ------------------------ |
| App 推送       | 系统通知栏推送（需授权） |
| 小程序服务通知 | 微信服务通知（需订阅）   |
| App 内消息     | 消息中心可查看历史通知   |

::: tip 已知替代
电费、成绩的低余额 / 更新提醒已可通过 [高级功能](/features/personalize) 的定时邮件任务实现，无需等待消息中心上线。
:::
